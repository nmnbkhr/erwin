# BAIW — Banking Analytics Intelligence Workbench

A professional React web application that integrates banking data model metadata, capability frameworks, maturity assessments, and Pakistan banking context into a single interactive consulting workbench.

## Quick Start

```bash
# Install dependencies
npm install

# Generate sample data (if not already present)
python3 scripts/generate_sample_data.py

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Modules

| Module | Route | Description |
|--------|-------|-------------|
| Dashboard | `/` | Key metrics, domain donut chart, capability bars, Pakistan stats |
| Model Explorer | `/model` | Browse 3,917 FSDM entities across 16 domains |
| Capability Navigator | `/capabilities` | Navigate 112 BVF capabilities with data requirements |
| Dependency Graph | `/graph` | Interactive D3 force-directed network visualization |
| Maturity Assessment | `/maturity` | BACR maturity wizard with 793 questions, radar chart results |
| Profitability Engine | `/profitability` | Star schema ERD, 15-line P&L builder, gap extensions |
| Roadmap Builder | `/roadmap` | Select capabilities, generate phased implementation roadmap |
| Pakistan Reference | `/pakistan` | SBP regulatory framework, Islamic banking, payment ecosystem |

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Recharts (charts)
- D3.js (force-directed graph)
- Lucide React (icons)
- React Router v6

## Data

Sample data is generated by `scripts/generate_sample_data.py` and placed in `src/data/`. When real CSV files are available from the erwin repo, use `scripts/prepare_data.py` to convert them.

## Build

```bash
npm run build
```

Output is in the `dist/` directory.
